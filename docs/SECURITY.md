# Security policy

Lindar is in public preview. Use of this preview in critical applications is strongly discouraged. This policy applies to the preview and may change before 1.0.

## Public reports

GitHub Issues are the normal reporting channel at this stage. Please report allocation errors, invalid pointer access, buffer overflows and similar defects there, except in the circumstances described below. Pull requests with fixes and regression tests are welcome.

Include the Lindar revision, platform, build configuration, steps to reproduce and relevant diagnostics. A small reproducer or input file is helpful.

## Private reports

Direct email contact is recommended only when both conditions are confirmed:

- This preview of Lindar is already in use in a critical application.
- The defect permits privilege escalation, arbitrary code execution or a comparably serious impact in that application.

In that case, email [dawidpieper@o2.pl](mailto:dawidpieper@o2.pl?cc=d.pieper%40prowadnica.org), preferably with `d.pieper@prowadnica.org` in CC, before publishing the details in an Issue or pull request. Describe the affected application, Lindar revision and confirmed impact.

Thank you for reporting problems and helping improve Lindar.
